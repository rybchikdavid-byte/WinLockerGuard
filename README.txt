# Варгуард (WinLockerGuard)

Сторож для Windows против винлокеров («Ваш компьютер заблокирован», вымогатели,
блокировщики экрана) и пранков вроде «Вас заметили» с глазом. Работает тихо в
фоне, проверяет экран каждые 0,7 секунды, при нападении убивает процесс вместе
с дочерними, снимает блокировку ввода, убирает заразу из автозапуска,
планировщика, служб и ярлыков, а файл отправляет в карантин (или удаляет
навсегда — по настройке).

Это **не** замена Защитнику Windows. Не отключай его.

## Запуск — просто открой EXE

1. Распакуй архив.
2. Дважды щёлкни **WinLockerGuard.exe**.

Всё. Никакого бата, никаких вопросов и никакого UAC: программа сама тихо
переезжает в `C:\Users\Имя\AppData\Local\WinLockerGuard`, прописывается в
автозапуск текущего пользователя, включает защиту и открывает блокнот с
приветствием. Блокнот можно закрыть — защита останется работать, значок будет
рядом с часами.

Если программу убили — её поднимет встроенный сторож в течение 15 секунд.
Остановить совсем: правый клик по значку → «Выход (остановить защиту)».

Есть и второй, администраторский способ: **Install.bat**. Он ставит программу в
`C:\ProgramData\WinLockerGuard`, запускает от админа при входе и умеет убивать
процессы, запущенные с повышенными правами. Требует подтверждения UAC.

Если SmartScreen ругается на неизвестный файл — это потому, что программа
не подписана платной подписью. «Подробнее» → «Выполнить всё равно».

Защитник Windows может ругаться на программу, которая убивает процессы и чистит
автозапуск; не отключай Защитник, а при необходимости добавь папку
`C:\Users\Имя\AppData\Local\WinLockerGuard` в исключения.

## Где лежит

Без администратора (обычный запуск EXE):

- Программа: `C:\Users\Имя\AppData\Local\WinLockerGuard\WinLockerGuard.exe`
- Журнал: `C:\Users\Имя\AppData\Local\WinLockerGuard\guard.log`
- Карантин: `...\WinLockerGuard\Quarantine`
- Настройки: `...\WinLockerGuard\settings.ini`
- Приветствие: `...\WinLockerGuard\Привет от Варгуарда.txt`
- Автозапуск: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`

С администратором (Install.bat): всё то же в `C:\ProgramData\WinLockerGuard`,
плюс задачи `WinLockerGuard` (при входе) и `WinLockerGuardWatchdog` (раз в
минуту).

## Что именно делает при обнаружении

1. Открывает ввод, если винлокер его заблокировал (`BlockInput`, курсор).
2. Убивает процесс и всё его дерево (`taskkill /F /T`).
3. Удаляет его записи из `Run`/`RunOnce` (HKLM и HKCU, 32 и 64 бита).
4. Удаляет задачу планировщика, если она запускает этот файл.
5. Удаляет службу, если она запускает этот файл.
6. Удаляет ярлык из папок «Автозагрузка».
7. Забирает сам файл: по умолчанию переносит в карантин, при
   `PermanentDelete=1` — стирает навсегда. Если файл занят, ставит удаление
   при перезагрузке.

Всё пишется в `guard.log` с временем, PID и путём.

## Настройки

Файл `settings.ini` (создаётся при установке):

```ini
# 1 = стирать найденные файлы сразу, 0 = сначала в карантин
PermanentDelete=0
# как часто проверять экран, миллисекунды
ScanIntervalMs=700
# как часто проверять автозапуск, секунды
AutostartScanSeconds=5
# показывать значок в трее
ShowTray=1
# ловить чёрные полноэкранные пранки без текста («Вас заметили»)
DetectPrankFullscreen=1
```

После правки перезапусти программу (выйди из системы или заверши процесс
`WinLockerGuard` в диспетчере — сторож поднимет его через минуту).

**Карантин — это безопасно:** файл переименован в `.quarantine` и лежит
обезвреженным. Оригинала по старому пути уже нет, вирус мёртв. Значок в трее →
«Очистить карантин» стирает всё навсегда. Если хочешь, чтобы программа вообще
не хранила найденное, поставь `PermanentDelete=1`.

## Что он ловит

- Полноэкранное окно поверх всех с текстом про блокировку, полицию, выкуп,
  биткоин, SMS, «файлы зашифрованы» — типичный винлокер.
- Пранк «Вас заметили» и подобные: чёрный экран с глазом, где текст нарисован
  картинкой и в окне его нет. Программа смотрит на сам экран: полноэкранное
  окно поверх всех из пользовательской папки, без данных о версии и с тёмной
  картинкой — гасится. Имя файла вроде `Вас заметили.exe`, `noticed.exe`,
  `prank.exe` тоже ловится.
- Запись автозапуска, которая ведёт на подозрительный `.exe` в Temp, Downloads,
  AppData и т.п. с именем вроде `winlock`, `locker`, `ransom`, `cryptolocker`.
- Ярлык автозагрузки на такой файл.
- Задачу планировщика или службу, запускающую уже пойманный файл.

Системные процессы (`explorer`, `winlogon`, `svchost`, `csrss`, Defender и др.)
не трогает. Файлы из `C:\Windows` и `C:\Program Files` не удаляет — только
сообщает в журнал, чтобы не сломать систему.

## Чего он не умеет

- Не расшифровывает файлы, которые шифровальщик уже испортил. Для этого нужны
  резервные копии или ключ.
- Не вычищает загрузочные (MBR/UEFI) вирусы и руткиты — тут нужна загрузочная
  флешка и полное антивирусное сканирование.
- Не заменяет Защитник Windows и здравый смысл.
- Эвристика может ошибиться: если в полноэкранном окне с текстом про «выкуп»
  окажется легальная программа, она будет закрыта, а файл — в карантине.
  Проверяй журнал; из карантина можно достать файл обратно.

## Удаление

Если запускал просто EXE:

1. Правый клик по значку в трее → «Выход (остановить защиту)».
2. Удали папку `C:\Users\Имя\AppData\Local\WinLockerGuard`.
3. В `regedit` удали `WinLockerGuard` из
   `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`.

Если ставил через Install.bat — запусти **Uninstall.bat** и разреши админ.
Карантин останется — его можно стереть вручную (`Quarantine` в папке программы).

## Важно

Ставь только на свой компьютер или на тот, владелец которого разрешил.
Скрипт удаляет файлы и службы — это необратимо при `PermanentDelete=1`.
Сделай точку восстановления перед первым запуском.
